# Brief D1 — Chuẩn bị triển khai miễn phí (chỉ viết tệp cấu hình + tài liệu)

Đọc `AGENTS.md`, `DEPLOY.md`, `docs/ROADMAP.md` (Giai đoạn 4), `docker/api.Dockerfile`, `docker/web.Dockerfile`, `api/app/config.py`, `api/app/main.py`. Chỉ tạo/sửa: `render.yaml` (gốc repo, MỚI), `web/vercel.json` (MỚI, nếu cần), `docs/DEPLOY_FREE.md` (MỚI), `api/app/config.py` + test mới `api/tests/test_production_guard.py` (mục 3), `.env.example` (chỉ thêm biến mới có chú thích). KHÔNG chạy shell, KHÔNG tạo tài khoản/triển khai, KHÔNG ghi bí mật thật vào file, không commit.

Mục tiêu: dựng bản chạy công khai bằng **gói miễn phí**: web Next.js trên **Vercel (Hobby)**, API FastAPI trên **Render (free web service, Docker)**, Postgres trên **Neon (free)** (Render Postgres miễn phí hết hạn 30 ngày nên KHÔNG dùng; Neon free còn giữ dữ liệu, hỗ trợ pg_trgm/unaccent).

1. `render.yaml`: một web service `uelcourses-api` (runtime docker, `dockerfilePath: docker/api.Dockerfile`, context gốc repo hoặc đúng như Dockerfile yêu cầu — đọc Dockerfile), `plan: free`, `healthCheckPath: /api/health`, biến môi trường: `DATABASE_URL` (`sync: false`, người dùng tự dán chuỗi Neon), `SESSION_SECRET` (`generateValue: true`), `CORS_ORIGINS` (`sync: false`), `AUTO_SEED=false`, `ENV=production`, `FRONTEND_BASE_URL`, `OAUTH_REDIRECT_BASE` (`sync: false`). Chạy migration khi khởi động: dùng `preDeployCommand`/lệnh khởi động `alembic upgrade head && uvicorn …` phù hợp (kiểm tra Dockerfile hiện tại đã làm chưa, tránh làm hai lần).
2. `web/vercel.json` hoặc hướng dẫn: Root Directory `web`, biến `NEXT_PUBLIC_API_URL` = URL Render, `NEXT_PUBLIC_USE_MOCKS` KHÔNG đặt (mặc định tắt). Chỉ tạo vercel.json nếu thật sự cần.
3. **Chốt chặn production:** trong `config.py`, nếu biến `ENV=production` mà `SESSION_SECRET` vẫn là mặc định `dev-only-change-me` hoặc `CORS_ORIGINS` chứa `localhost`, thì khi khởi động API ném lỗi rõ ràng (RuntimeError) — ở mức hàm `validate_production(settings)` được gọi từ `lifespan` trong `main.py`; ở môi trường khác thì không ảnh hưởng. Test pytest cho cả hai trường hợp (đừng làm hỏng test hiện có; conftest không đặt ENV=production).
4. `docs/DEPLOY_FREE.md` (tiếng Việt, từng bước cho người không chuyên): (a) tạo project Neon, bật extension `pg_trgm`, `unaccent`; (b) khôi phục dữ liệu từ bản sao lưu `pg_restore --no-owner --no-acl -d "<chuỗi Neon>" data/db/backups/<file>.dump` (nêu cách tạo bản sao lưu mới bằng `pg_dump -Fc`) và chạy `alembic upgrade head`; (c) tạo dịch vụ Render từ `render.yaml` (Blueprint) và dán biến; lưu ý gói free ngủ sau ~15 phút không dùng → lần gọi đầu chậm; (d) import repo vào Vercel, đặt Root Directory `web` và `NEXT_PUBLIC_API_URL`; (e) cập nhật `CORS_ORIGINS` = URL Vercel; (f) kiểm tra: `/api/health`, mở trang chủ, xem nhãn "Mất kết nối" không xuất hiện; (g) bảng chi phí/giới hạn của gói miễn phí và khi nào phải trả tiền; (h) đăng nhập Google/Facebook cần OAuth client của chủ dự án (để sau). Không bịa số giới hạn cụ thể nếu không chắc: ghi "xem trang giá hiện hành của nhà cung cấp".

Tiêu chí xong: `cd api; python -m pytest -q --ignore=tests/rag` toàn bộ qua; báo cáo liệt kê file đã tạo và các giả định cần chủ dự án xác nhận.
